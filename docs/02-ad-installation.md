# Phase 2: Active Directory & OU Hierarchy Design

## Overview
Designing and implementing a tiered Organizational Unit (OU) structure in ADUC for organized resource management.

## OU Structure
- `CORP.LOCAL`
  - `Corp_Admins`
  - `Corp_Users`
    - `IT`
    - `Finance`
    - `HR`
  - `Corp_Groups`
  - `Corp_Computers`
